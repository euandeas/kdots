# kdots

Default dotfiles for [Kansora](https://github.com/euandeas/kansora), managed with
[mise](https://mise.jdx.dev/dotfiles.html).

## How it works

[`mise/kansora.toml`](mise/kansora.toml) is installed as mise's system config. Your
own `~/.config/mise/config.toml` sits on top, so any entry with the same path
replaces Kansora's.

At login, `kansora-dots apply` deploys any file that's missing and never touches
ones you've changed. It also has DMS generate its default keybinds. Kansora adds Mod+E for Dux Files.

| File | Kind |
|---|---|
| `~/.config/niri/config.kdl` | managed symlink, follows updates. Includes DMS's files, then `local.kdl` |
| `~/.config/niri/local.kdl` | yours, for niri overrides |
| `~/.config/ghostty/config` | yours |
| `~/.config/dms/settings.json` | yours. Selects the Flexoki theme and Commit Mono, compact density, a smooth (no bounce) spring, a Pill password box on the lock and login screens, and the Kansora K on the bar's launcher button. The bar and lock-screen widgets are DMS's defaults otherwise |
| `~/.config/dms/clsettings.json` | yours. Clipboard history: 100 entries, cleared after 2 days and at login |
| `~/.local/state/dms/session.json` | yours. Flexoki wallpapers for light/dark mode |
| `~/.config/niri/dms/*.kdl` | generated by DMS (`dms setup`) |

fastfetch's default config is system-wide in `/etc/xdg/fastfetch/config.jsonc`
([`fastfetch/config.jsonc`](fastfetch/config.jsonc)). Put your own in
`~/.config/fastfetch/config.jsonc` to replace it.

## Commands

```sh
kansora-dots status          # what's applied
kansora-dots reset <path>    # restore a default (your copy is backed up)
kansora-dots reset-all
```

To replace or disable a default, add it to your own mise config:

```toml
[dotfiles]
"~/.config/ghostty/config" = { source = "ghostty/config" }
"~/.config/niri/local.kdl" = { enabled = false }
```

## Building

Kansora's workflows build and publish the `kansora-dots` RPM, and
[`check.yml`](.github/workflows/check.yml) tests each commit here. See
[kansora/docs/building.md](https://github.com/euandeas/kansora/blob/main/docs/building.md).
